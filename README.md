# Nuestra historia

Experiencia de aniversario hecha con HTML5, CSS3 y JavaScript Vanilla. No requiere instalación ni dependencias.

## Ejecutar en Visual Studio Code

Abre la carpeta `nuestra-historia` en VS Code y abre `index.html` en el navegador. Para una vista más cómoda, puedes usar la extensión **Live Server** y pulsar **Go Live**.

## Personalizar

- Cambia `anniversaryDate` en `js/script.js` por la fecha real, por ejemplo `2025-04-04T18:30:00`.
- Edita títulos y fotografías en `CONFIG.memories`.
- Reemplaza las imágenes dentro de `assets/` conservando sus nombres, o actualiza las rutas en la configuración.
- Los espacios de Videos, Fotos y Playlist muestran un mensaje preparado para conectar posteriormente cada contenido.

Las imágenes actuales son las seis fotografías proporcionadas en `Imagenes`. Los personajes son ilustraciones decorativas originales construidas con CSS, sin recursos externos obligatorios.
